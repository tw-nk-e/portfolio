## Ce portfolio, en détail

Site statique en **MDX** rendu par **Nextra 4**, déployé automatiquement sur
GitHub Pages via GitHub Actions à chaque push sur `main`. Pas de serveur à
maintenir : le build produit du HTML statique.

Ce que ça m'a appris : la structure App Router de Next.js, la génération de
pages statiques, et le fonctionnement d'un pipeline de déploiement de bout en
bout.
